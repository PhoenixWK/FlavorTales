MongoDB – Document Store

Lưu trữ dữ liệu không cấu trúc, schema linh hoạt: tourist sessions & visitor analytics.

Tổng quan MongoDB Architecture

MongoDB 7

📦 tourist_sessions

Ephemeral – auto-deleted sau 24h

→ Tracking ẩn danh (UUID, không PII)

→ Lưu viewed POIs, played audio

→ Language preference BCP-47

TTL Index: expires_at (expireAfterSeconds=0)

📊 visitor_events

Permanent – lưu vĩnh viễn cho analytics

→ 1 event per session (auto via Spring Event)

→ Index timestamp cho time-range queries

→ Dùng MongoTemplate aggregation

Không có TTL – retained indefinitely

EVENT FLOW

Tourist API Request → LocationService → new TouristSession → ApplicationEvent → new VisitorEvent
db.tourist_sessions
24h TTL flavortales-location module
Lưu session ẩn danh của tourist. Tự động xoá sau 24h qua MongoDB TTL index. Không lưu PII.
FieldBSON TypeIndexMô tả
_id (sessionId)StringPKRandom UUID – unpredictable, non-sequential (bảo mật)
language_preferenceString—BCP-47 tag (e.g. "vi", "en"). Default: "vi"
viewed_poi_idsArray<Int32>—Danh sách poi_id đã xem trong session; ref tới MySQL poi.poi_id
played_audio_idsArray<Int32>—Danh sách audio_id đã phát; ref tới MySQL audio.audio_id
created_atDate—Thời điểm tạo session
expires_atDateTTL (expireAfterSeconds=0)Hết hạn sau 24h; MongoDB tự xoá document khi expires_at < now
Index: TTL index trên expires_at với expireAfterSeconds: 0 — MongoDB background job chạy mỗi ~60s để cleanup.

db.visitor_events
Permanent flavortales-analytics module
Analytics event records. 1 document per tourist session. Không có TTL – lưu lại để phân tích lịch sử.
FieldBSON TypeIndexMô tả
_id (id)StringPKUUID auto-generated
timestampDateIndex (@Indexed)Thời điểm visit; dùng cho time-range aggregation queries
Aggregation dùng MongoTemplate: group by date, count visitors per day/week/month cho dashboard analytics.

Redis – Cache Layer

Read-through cache cho POI và Audio module. Graceful degradation – Redis failure không ảnh hưởng tới service.

Configuration

Redis 7.2

CONNECTION

Host: localhost (env: REDIS_HOST)
Port: 6379 (env: REDIS_PORT)
Serialization: Jackson JSON + JavaTimeModule
Type info: PROPERTY polymorphic

JEDIS POOL (redis.yml)

max-active: 8
max-idle: 8
max-wait: 1000ms
RedisTemplate beans: poiRedisTemplate (@Primary) + audioRedisTemplate
⚠️ Graceful Degradation: Cả POI và Audio cache service đều catch mọi Redis exception và fallback về MySQL query. Lỗi Redis không bao giờ propagate lên caller.

TTL30 giây (processing) / 24 giờ (completed/failed)
