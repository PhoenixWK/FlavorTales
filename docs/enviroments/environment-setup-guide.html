1. Tổng quan môi trường

FlavorTales là nền tảng food-tourism với kiến trúc monorepo gồm bốn thành phần chính: Backend (Spring Boot), Frontend (Next.js), Database (MySQL + Redis + MongoDB) và Infrastructure (Docker Compose). Dự án hỗ trợ bốn môi trường:

Môi trườngMục đíchCách chạyURL mặc định
Dev Phát triển local cho lập trình viên Chạy trực tiếp (Maven + npm) http://localhost:3000
Test Chạy unit test & integration test tự động Maven Surefire / Vitest –
Staging Kiểm thử trước khi release, gần giống prod Docker Compose (infra docker-compose) Port ánh xạ local
Prod Triển khai thật, expose qua Cloudflare Tunnel Docker Compose (infra docker-compose) + Cloudflare https://flavortales.site
Lưu ý về branch Dự án có 4 nhánh làm việc độc lập, không theo thứ tự phụ thuộc lẫn nhau:
  • backend – phát triển Spring Boot API
  • frontend – phát triển Next.js UI
  • infrastructure – cấu hình Docker, CI/CD
  • database – schema, migration, seed data
Sau khi commit đầy đủ trên từng nhánh, mới merge tất cả vào main. Không được merge trực tiếp feature branch vào main khi chưa hoàn thiện.

3. Môi trường Development (Local)

Phù hợp cho quá trình phát triển hàng ngày. Backend & Frontend chạy trực tiếp trên máy; Database stack chạy qua Docker Compose.

3.1 Khởi động Database Stack

Các dịch vụ cơ sở dữ liệu (MySQL primary + replica, Redis, MongoDB) được quản lý bằng Docker Compose trong thư mục infrastructure/.

  1. Mở terminal và di chuyển vào thư mục infrastructure/ 
    cd "d:\Codes\Seminar\Source Code\infrastructure"
  2. Khởi động các dịch vụ (chỉ cần khởi động database, không build image app): 
    docker compose up -d mysql-primary mysql-replicate replication-setup redis mongodb
  3. Kiểm tra trạng thái các container: 
    docker compose ps
    Tất cả container phải có trạng thái healthy trước khi chạy backend.
  4. Xem log nếu cần debug: 
    docker compose logs -f mysql-primary
docker compose logs -f replication-setup
💡 MySQL Replication Container replication-setup sẽ tự động cấu hình GTID replication giữa primary (port 3308) và replica (port 3309). Đây là one-time setup, container có thể ở trạng thái Exited (0) sau khi hoàn thành.

3.2 Khởi động Backend

  1. Mở terminal và di chuyển vào thư mục backend/: 
    cd "d:\Codes\Seminar\Source Code\backend"
  2. Set JAVA_HOME (nếu chưa set trong hệ thống): 
    # Windows PowerShell
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.10.7-hotspot"
  3. Chạy Spring Boot application: 
    ./mvnw.cmd spring-boot:run -pl flavortales-app
    Backend sẽ start tại http://localhost:8080
  4. (Tùy chọn) Chạy qua VS Code Task:
    Nhấn Ctrl+Shift+P → Tasks: Run Task → Run FlavorTalesApplication
Cấu hình mặc định Development File backend/flavortales-app/src/main/resources/database-dev.yml dùng kết nối:
MySQL Primary: localhost:3308 | MySQL Replica: localhost:3309 | Redis: localhost:6379 | MongoDB: localhost:27017

3.3 Khởi động Frontend

  1. Di chuyển vào thư mục frontend/: 
    cd "d:\Codes\Seminar\Source Code\frontend"
  2. Cài đặt dependencies (chỉ cần lần đầu hoặc khi package.json thay đổi): 
    npm ci
  3. Chạy development server: 
    npm run dev
    Frontend sẽ chạy tại http://localhost:3000

4. Môi trường Test

4.1 Backend Tests (JUnit 5)

Chạy toàn bộ test suite:

cd backend
./mvnw.cmd test

Chạy test cho một module cụ thể:

./mvnw.cmd test -pl flavortales-auth
./mvnw.cmd test -pl flavortales-user
./mvnw.cmd test -pl flavortales-poi

Chạy một test class hoặc method cụ thể:

./mvnw.cmd test -pl flavortales-auth -Dtest=AuthServiceTest
./mvnw.cmd test -pl flavortales-auth -Dtest=AuthServiceTest#testLogin
💡 Cấu trúc test Unit test dùng @ExtendWith(MockitoExtension.class), Integration test dùng @SpringBootTest. Test files đặt trong src/test/java/ theo cùng package structure với src/main/java/.

4.2 Frontend Tests (Vitest)

Chạy test ở chế độ watch (phát triển):

cd frontend
npm run test

Chạy test một lần (CI/CD):

npm run test:run
Vị trí test files Co-locate với component source: *.test.ts(x) hoặc trong thư mục __tests__/. Dùng @testing-library/react cho component tests.

4.3 Load Test (Locust)

Kịch bản load test nằm tại test/locustfile.py:

# Cài Locust
pip install locust

# Chạy load test (backend phải đang chạy)
cd test
locust -f locustfile.py --host=http://localhost:8080

5. Môi trường Staging

Staging sử dụng toàn bộ Docker Compose stack (bao gồm cả backend & frontend được build thành image), mô phỏng gần đúng môi trường production nhưng chạy local.

5.1 Chuẩn bị file .env

Tạo file .env trong thư mục infrastructure/ dựa theo mẫu:

# infrastructure/.env

# ── Database ──────────────────────────────────────────────────────
DB_USERNAME=root
DB_PASSWORD=root

# ── JWT ───────────────────────────────────────────────────────────
# Tạo secret: openssl rand -base64 32
APP_JWT_SECRET=your-256-bit-secret-key-here

# ── Email (Gmail SMTP) ───────────────────────────────────────────
SPRING_MAIL_USERNAME=your-email@gmail.com
SPRING_MAIL_PASSWORD=your-app-password

# ── Cloudflare R2 ─────────────────────────────────────────────────
R2_ACCOUNT_ID=your-account-id
R2_ACCESS_KEY=your-r2-access-key
R2_SECRET_KEY=your-r2-secret-key
R2_PUBLIC_URL=https://cdn.flavortales.site

# ── Frontend ──────────────────────────────────────────────────────
NEXT_PUBLIC_API_BASE_URL=http://localhost:8080
NEXT_PUBLIC_R2_PUBLIC_URL=https://cdn.flavortales.site

# ── CORS ──────────────────────────────────────────────────────────
APP_CORS_ALLOWED_ORIGINS=http://localhost:3000

# ── Cloudflare Tunnel (chỉ dùng cho staging/prod) ────────────────
# CLOUDFLARE_TUNNEL_TOKEN=your-tunnel-token
🔒 Bảo mật Không commit file .env lên Git. Đảm bảo .env có trong .gitignore.

5.2 Build & Chạy toàn bộ Stack

  1. Di chuyển vào thư mục infrastructure/: 
    cd "d:\Codes\Seminar\Source Code\infrastructure"
  2. Build images và khởi động toàn bộ stack: 
    docker compose up -d --build
  3. Theo dõi quá trình khởi động (đặc biệt là database health check): 
    docker compose logs -f
  4. Kiểm tra trạng thái: 
    docker compose ps

5.3 Quản lý Stack

# Dừng tất cả container
docker compose stop

# Dừng và xoá container (giữ volume)
docker compose down

# Dừng và xoá container + volume (reset hoàn toàn dữ liệu)
docker compose down -v

# Restart một service cụ thể
docker compose restart backend

# Xem log của một service
docker compose logs -f frontend
⚠️ Thứ tự khởi động Backend phụ thuộc vào mysql-primary, mysql-replicate, replication-setup, redis, mongodb đều phải healthy trước. Nếu backend fail, kiểm tra health check của database containers.

6. Môi trường Production

Production triển khai trên máy chủ thông qua Docker Compose kết hợp với Cloudflare Tunnel để expose dịch vụ mà không cần mở inbound port.

6.1 Cấu trúc hạ tầng Production

Dịch vụDomainRouting
Frontendhttps://flavortales.siteCloudflare Tunnel → frontend:3000
Backend APIhttps://api.flavortales.siteCloudflare Tunnel → backend:8080
CDN / File Storagehttps://cdn.flavortales.siteCloudflare R2 (S3-compatible)

6.2 Cài đặt Cloudflare Tunnel

  1. Tạo tunnel trong Cloudflare Zero Trust Dashboard (one.dash.cloudflare.com)
  2. Cấu hình 2 Public Hostname:
    • flavortales.site → http://frontend:3000
    • api.flavortales.site → http://backend:8080
  3. Sao chép Tunnel Token và thêm vào file .env: 
    CLOUDFLARE_TUNNEL_TOKEN=eyJhIjoixxxxxxxxxxxxxxxx...
  4. Uncomment dịch vụ cloudflared trong docker-compose.yml hoặc thêm vào file override.

6.3 Biến môi trường Production (bổ sung)

# infrastructure/.env (production additions)

# ── Cloudflare Tunnel ────────────────────────────────────────────
CLOUDFLARE_TUNNEL_TOKEN=your-production-tunnel-token

# ── Frontend URLs ─────────────────────────────────────────────────
NEXT_PUBLIC_API_BASE_URL=https://api.flavortales.site
NEXT_PUBLIC_R2_PUBLIC_URL=https://cdn.flavortales.site

# ── CORS ──────────────────────────────────────────────────────────
APP_CORS_ALLOWED_ORIGINS=https://flavortales.site

# ── Cookie bảo mật (HTTPS) ────────────────────────────────────────
# Trong security.yml: cookie-secure: true

6.4 Triển khai Production

cd infrastructure

# Pull image mới nhất và rebuild nếu có thay đổi code
docker compose pull
docker compose up -d --build

# Kiểm tra tất cả services healthy
docker compose ps

6.5 Backup Database

# Backup MySQL (chạy trên máy chủ hoặc trong container)
docker exec flavortales-primary \
  mysqldump -uroot -p"${DB_PASSWORD}" flavortales \
  > flavortales_backup_$(date +%Y%m%d).sql

# Restore từ backup
docker exec -i flavortales-primary \
  mysql -uroot -p"${DB_PASSWORD}" flavortales \
  < flavortales_backup.sql
🔒 Checklist bảo mật Production
  • APP_JWT_SECRET phải là chuỗi ngẫu nhiên 256-bit (không dùng giá trị dev)
  • cookie-secure: true trong security.yml (chỉ dùng HTTPS)
  • Đổi password MySQL mặc định (root/root)
  • Không expose port MySQL/Redis/MongoDB ra ngoài container network
  • File .env không được commit lên Git

7. Biến môi trường & Cấu hình

Tất cả biến môi trường được đọc bởi Spring Boot qua cú pháp ${VAR_NAME:default-value}. Khi chạy Docker Compose, các biến được cung cấp qua file infrastructure/.env.

7.1 Database

  • DB_USERNAME Username MySQL (master & slave) default: root
  • DB_PASSWORD Password MySQL default: root
  • SPRING_DATASOURCE_MASTER_JDBC_URL JDBC URL cho MySQL primary (override trong Docker) default: jdbc:mysql://localhost:3308/flavortales
  • SPRING_DATASOURCE_SLAVE_JDBC_URL JDBC URL cho MySQL replica (override trong Docker) default: jdbc:mysql://localhost:3309/flavortales
  • REDIS_HOST Hostname Redis server default: localhost
  • REDIS_PORT Port Redis server default: 6379
  • MONGODB_URI MongoDB connection URI default: mongodb://localhost:27017/flavortales

7.2 Bảo mật & JWT

  • APP_JWT_SECRET Secret key để ký JWT token. Tạo bằng: openssl rand -base64 32 Required (Prod)
  • APP_CORS_ALLOWED_ORIGINS Danh sách origin được phép CORS (phân cách bằng dấu phẩy) default: http://localhost:3000

7.3 Email (Gmail SMTP)

  • SPRING_MAIL_USERNAME Gmail address dùng để gửi email xác thực & thông báo Required
  • SPRING_MAIL_PASSWORD Gmail App Password (không phải mật khẩu Gmail thường). Tạo tại Google Account → Security → App Passwords Required

7.4 Cloudflare R2 (File Storage)

  • R2_ACCOUNT_ID Cloudflare Account ID (lấy từ Cloudflare Dashboard) Required
  • R2_ACCESS_KEY R2 API Token Access Key Required
  • R2_SECRET_KEY R2 API Token Secret Key Required
  • R2_PUBLIC_URL Public URL cho R2 bucket (custom domain) default: https://cdn.flavortales.site

7.5 Frontend

  • NEXT_PUBLIC_API_BASE_URL URL gốc của Backend API (client-side). Được inject lúc build. default: http://localhost:8080
  • NEXT_PUBLIC_R2_PUBLIC_URL Public CDN URL để load ảnh/file. Được inject lúc build. default: https://cdn.flavortales.site
  • INTERNAL_API_BASE_URL URL Backend dùng cho Server-Side BFF routing (server-to-server, không qua browser). Trong Docker dùng service hostname. default: http://backend:8080

7.6 Cloudflare Tunnel

  • CLOUDFLARE_TUNNEL_TOKEN Token để authenticate cloudflared với Cloudflare (chỉ cần cho staging/prod) Staging/Prod only

9. Remote Access qua Tailscale

Tailscale tạo mạng VPN mesh (dựa trên WireGuard), cho phép kết nối trực tiếp từ laptop vào Mini PC chạy server mà không cần mở port router hay cấu hình firewall phức tạp.

💡 Use case Mini PC đặt ở nhà/phòng trọ chạy Docker stack 24/7. Laptop ở trường dùng WiFi trường hoặc 4G để SSH, kết nối MySQL Workbench, MongoDB Compass vào Mini PC qua Tailscale IP.

9.1 Cài đặt Tailscale trên Mini PC (Ubuntu Server)

  1. Cài Tailscale: 
    curl -fsSL https://tailscale.com/install.sh | sh
  2. Khởi động và đăng nhập (dùng Google hoặc GitHub account): 
    sudo tailscale up
    Trình duyệt sẽ mở link xác thực. Đăng nhập và xác nhận.
  3. Lấy IP Tailscale của Mini PC: 
    tailscale ip -4
# Ví dụ: 100.64.x.x
  4. Bật tự động khởi động cùng hệ thống: 
    sudo systemctl enable --now tailscaled

9.2 Cài đặt Tailscale trên Laptop (Windows)

  1. Tải và cài Tailscale tại tailscale.com/download
  2. Đăng nhập cùng account với Mini PC
  3. Kiểm tra kết nối: 
    ping 100.64.x.x

9.3 Kết nối các dịch vụ qua Tailscale IP

Dịch vụCông cụConnection String
SSHTerminalssh user@100.64.x.x
MySQL PrimaryMySQL WorkbenchHost: 100.64.x.x, Port: 3308, Method: Standard TCP/IP
MySQL ReplicaMySQL WorkbenchHost: 100.64.x.x, Port: 3309
MongoDBCompass / Studio 3Tmongodb://100.64.x.x:27017
RedisRedisInsightHost: 100.64.x.x, Port: 6379
Backend APIBrowser / Postmanhttp://100.64.x.x:8080
Không cần SSH Tunnel Khi dùng Tailscale, kết nối MySQL Workbench dùng Standard TCP/IP (không phải "Standard TCP/IP over SSH") vì Tailscale đã tạo kênh mạng riêng giữa 2 máy.

9.4 Bảo mật: Chặn SSH từ internet public

Sau khi cấu hình Tailscale, nên chặn SSH từ internet để tránh port scanning:

# Xóa rule allow SSH public
sudo ufw delete allow 22/tcp

# Chỉ cho phép SSH từ interface Tailscale
sudo ufw allow in on tailscale0 to any port 22

sudo ufw reload
sudo ufw status

9.5 Quản lý Tailscale

# Dừng kết nối Tailscale
sudo tailscale down

# Dừng service hoàn toàn
sudo systemctl stop tailscaled

# Tắt tự khởi động
sudo systemctl disable tailscaled

# Bật lại
sudo systemctl enable --now tailscaled
sudo tailscale up
⚠️ Yêu cầu kết nối internet Tailscale cần internet để duy trì kết nối qua coordination server. Mini PC phải có internet (WiFi nhà/phòng trọ, LAN, hoặc USB tethering 4G) thì laptop mới kết nối được từ bên ngoài.

10. Xử lý sự cố thường gặp

🔴 Backend không khởi động được

Lỗi: JAVA_HOME không đúng hoặc JDK không phải version 21 
# Kiểm tra version
java -version
# Nếu không phải JDK 21, set lại:
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.10.7-hotspot"
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
Lỗi: Connection refused khi kết nối MySQL Chắc chắn Docker containers đang chạy và healthy: 
docker compose ps
# mysql-primary và mysql-replicate phải ở trạng thái healthy
# Nếu không, xem log:
docker compose logs mysql-primary

🔴 Frontend lỗi build hoặc module not found

Xoá node_modules và cài lại 
cd frontend
Remove-Item -Recurse -Force node_modules
npm ci

🔴 MySQL Replication bị lỗi

Reset và sync lại replica từ backup 
docker compose down -v
docker compose up -d mysql-primary mysql-replicate replication-setup redis mongodb
# Chờ replication-setup hoàn thành, sau đó kiểm tra:
docker exec flavortales-replicate mysql -uroot -proot \
  -e "SHOW REPLICA STATUS\G" | grep -E "Running|Error"

🔴 Docker Compose build thất bại (backend)

Maven download lỗi do mạng không ổn định Dockerfile đã có retry logic tự động. Nếu vẫn lỗi: 
# Build lại không dùng cache
docker compose build --no-cache backend

🔴 Port đã được sử dụng

Kiểm tra và giải phóng port 
# Kiểm tra process đang dùng port (ví dụ: 3308)
netstat -ano | findstr :3308

# Kill process theo PID
Stop-Process -Id <PID> -Force

🔴 JWT Token bị reject

Trong môi trường Dev Biến mặc định là dev-local-secret-key-for-development-only-use. Nếu backend khởi động lại và secret thay đổi (ví dụ trong Docker với ENV khác), các token cũ sẽ không còn hợp lệ. Xoá cookie và đăng nhập lại.
