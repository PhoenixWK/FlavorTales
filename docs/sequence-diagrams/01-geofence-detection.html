Phase 3 – Client-Side Geofence Detection + Session Update

Frontend tính Haversine Distance → detect proximity → PATCH /api/tourist/sessions/{sessionId}

Actors

Tourist App (Leaflet Map) Browser Geolocation API TouristSessionController TouristSessionService MongoDB
Kiến trúc quan trọng: FlavorTales không gửi tọa độ tourist lên server để tính geofence. Server chỉ cung cấp List<POI> với lat/lng/radius, Frontend tự tính khoảng cách bằng Haversine formula. Khi vào vùng radius, app cập nhật viewedPoiIds trong session MongoDB.
sequenceDiagram autonumber participant GEO as Browser
Geolocation API participant App as Tourist App / Leaflet Map
(Frontend) participant SC as TouristSessionController
/api/tourist/sessions participant SS as TouristSessionService participant MDB as MongoDB App->>+GEO: navigator.geolocation.watchPosition() Note over GEO: Continuous location tracking GEO-->>-App: { latitude, longitude, accuracy } loop Mỗi lần vị trí thay đổi App->>App: Với mỗi POI trong danh sách:
distance = haversineMetres(
userLat, userLng,
poi.latitude, poi.longitude
) Note over App: Haversine Formula:
R = 6,371,000 m
a = sin²(Δlat/2) + cos(lat1)·cos(lat2)·sin²(Δlng/2)
d = 2R · atan2(√a, √(1-a)) alt distance ≤ poi.radius (tourist TRONG vùng POI) App->>App: Hiển thị content: shop name,
menu, audio guide, avatar App->>App: Highlight marker trên Leaflet map App->>App: Thêm poiId vào viewedPoiIds set App->>+SC: PATCH /api/tourist/sessions/{sessionId}
Body: UpdateSessionRequest {
viewedPoiIds: [poiId1, poiId2, ...] } SC->>+SS: updateSession(sessionId, request) SS->>+MDB: findBySessionId(sessionId)
check expiresAt > now MDB-->>SS: TouristSession document SS->>SS: Merge viewedPoiIds SS->>MDB: save(updatedSession) MDB-->>-SS: saved SS-->>-SC: TouristSessionResponse SC-->>-App: 200 OK else distance > poi.radius (tourist NGOÀI vùng POI) App->>App: POI marker bình thường
Không hiển thị content end end

Phase 4 – Tourist Vào Vùng Giao Thoa Của 2 POI

Haversine check trên tất cả POI → nhiều POI cùng active → hiển thị đồng thời, merge viewedPoiIds

Actors

Tourist App (Leaflet Map) Browser Geolocation API TouristSessionController TouristSessionService MongoDB
Trường hợp giao thoa: Vì frontend duyệt qua toàn bộ danh sách POI trong mỗi location update, nhiều POI có thể đồng thời thỏa điều kiện distance ≤ radius. Hệ thống không chọn ưu tiên – tất cả POI trong vùng đều được kích hoạt song song. Session update gộp tất cả poiId mới vào một PATCH request duy nhất để tránh race condition.
