Happy Path – Upload Ảnh Thành Công

POST /api/file/upload → FileService → R2FileStorageService → S3Client → Cloudflare R2 → INSERT file_asset

Actors

Client (Browser / Mobile App) JwtAuthenticationFilter FileController /api/file FileService [@Transactional] R2FileStorageService AWS S3Client SDK (v2) Cloudflare R2 Object Storage MySQL Primary (file_asset)
Endpoint được dùng bởi nhiều module: POI creation (avatar + gallery), Shop creation (avatar + gallery), User profile avatar. Mọi entity đều tham chiếu đến file_asset.id (fileId) thay vì lưu URL trực tiếp. Object key format: {username}/images/{originalFilename}. Public URL: {R2_PUBLIC_URL}/{objectKey}.
