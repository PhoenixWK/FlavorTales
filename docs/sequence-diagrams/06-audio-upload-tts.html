Phase 1 – Preview TTS (Không lưu vào DB)

Vendor nghe thử audio trước khi tạo chính thức · POST /api/audio/tts/preview → stream MP3 bytes

Actors

Vendor App (Frontend) JwtAuthenticationFilter AudioController /api/audio AudioService GoogleCloudTtsService
Không lưu: Preview chỉ stream bytes MP3 về frontend để nghe thử. Không upload lên R2, không INSERT vào DB. Vendor dùng để kiểm tra giọng đọc trước khi xác nhận tạo audio chính thức.
sequenceDiagram autonumber participant V as Vendor App participant JWT as JwtAuthFilter participant AC as AudioController participant AS as AudioService participant TTS as GoogleCloudTtsService V->>JWT: POST /api/audio/tts/preview
{text, language} JWT-->>V: 401 nếu token không hợp lệ JWT->>AC: authenticated (ROLE_vendor) AC->>AS: generatePreviewBytes(TtsRequest, vendorEmail) AS->>TTS: synthesize(text, languageCode, voiceName) note over TTS: HTTP POST → Google Cloud TTS API
Gửi text + languageCode + voiceName
Nhận audioContent (base64) TTS-->>AS: base64 audioContent AS->>AS: Base64.decode() + validate MP3 header AS-->>AC: byte[] mp3Bytes AC-->>V: 200 OK
Content-Type: audio/mpeg
Body: raw MP3 bytes note over V: Browser phát audio trực tiếp
Không gọi thêm bất kỳ API nào

Phase 2 – Tạo TTS Chính Thức & Lưu vào DB

POST /api/audio/shop/{shopId}/tts → Synthesize → R2 → file_asset → audio record (status=pending)

Actors

Vendor App (Frontend) JwtAuthenticationFilter AudioController /api/audio AudioService GoogleCloudTtsService R2FileStorageService MySQL (file_asset + audio) Redis (AudioCacheService)
Unique constraint: Bảng audio có UNIQUE KEY (shop_id, language_code). Nếu vendor upload lại cùng ngôn ngữ → upsertAudioRecord() sẽ UPDATE thay vì INSERT.
sequenceDiagram autonumber participant V as Vendor App participant JWT as JwtAuthFilter participant AC as AudioController participant AS as AudioService participant TTS as GoogleCloudTtsService participant R2 as R2FileStorageService participant DB as MySQL participant Cache as Redis V->>JWT: POST /api/audio/shop/{shopId}/tts
{text, language} JWT->>AC: authenticated (ROLE_vendor) AC->>AS: generateSingleAudio(TtsRequest, vendorEmail, shopId) AS->>AS: resolveVendorId(vendorEmail)
SELECT user_id FROM users WHERE email=? AS->>TTS: synthesize(text, languageCode, voiceName) note over TTS: Google Cloud TTS API
Trả về base64 audioContent TTS-->>AS: byte[] mp3Bytes AS->>R2: uploadBytes(mp3Bytes, objectKey, "audio/mpeg") note over R2: objectKey = "audio/{vendorId}/{shopId}/{lang}/{uuid}.mp3" R2-->>AS: fileUrl (public CDN URL) AS->>DB: INSERT INTO file_asset
(file_key, file_url, file_type, file_size, uploaded_by) DB-->>AS: fileId (INT) AS->>DB: upsertAudioRecord(shopId, fileId, languageCode,
ttsProvider='google_tts', processingStatus='completed') note over DB: INSERT ... ON DUPLICATE KEY UPDATE
Unique: (shop_id, language_code) DB-->>AS: audioId (INT) AS->>Cache: evictByShop(shopId)
DEL audio:shop:{shopId} AS-->>AC: TtsResponse{audioId, fileId, fileUrl, language} AC-->>V: 201 Created
{audioId, fileId, fileUrl, language, durationSeconds} note over V: Audio status = 'pending'
Cần admin duyệt mới thành 'active'

Phase 4 – Luồng Status Audio (pending → active)

Audio sau khi tạo có status=pending, cần admin duyệt mới tourist nghe được

Lưu ý quan trọng: Audio status và processing_status là hai trường độc lập. processing_status='completed' chỉ xác nhận TTS đã xong. status='active' mới cho phép tourist nghe được.
sequenceDiagram autonumber participant V as Vendor participant Sys as AudioService participant DB as MySQL audio table participant Admin as Admin participant Cache as Redis participant T as Tourist App V->>Sys: POST /api/audio/shop/{shopId}/tts Sys->>DB: INSERT audio (status='pending', processing_status='completed') DB-->>V: audioId returned note over DB: status = pending
Tourist chưa thể nghe Admin->>DB: (thông qua Shop approval flow)
UPDATE audio SET status='active'
WHERE shop_id = ? DB->>Cache: evictByShop(shopId) + evictByPoi(poiId) T->>Sys: GET /api/audio/poi/{poiId} Sys->>DB: SELECT WHERE status='active' DB-->>T: [{audioId, fileUrl, languageCode, ...}] note over T: Tourist nghe audio theo ngôn ngữ
đang chọn trong session
