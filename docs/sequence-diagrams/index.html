Tourist Check-in / Geofence Detection

Tourist tạo anonymous session (MongoDB), fetch danh sách POI active (Redis cache + MySQL Replica), sau đó frontend tính khoảng cách Haversine client-side để phát hiện khi tourist vào vùng POI. Cập nhật viewedPoiIds trong session.

Image Upload to Cloudflare R2

Validate MIME (image/jpeg/image/png) + size (≤ 5MB) → buildImageKey() tạo object key → S3Client.putObject(PutObjectRequest) → INSERT file_asset → trả về {fileId, fileUrl}. Bao gồm error cases và cách fileId được tái dùng bởi POI và Shop.

Vendor Tạo Audio Thuyết Minh (TTS & Upload)

Vendor nhập text → preview MP3 (stream bytes, không lưu DB) → xác nhận tạo chính thức: AudioService gọi Google Cloud TTS → upload MP3 lên R2 → INSERT file_asset → upsertAudioRecord() (UNIQUE shop+language). Redis cache evict sau mỗi lần ghi. Audio status bắt đầu bằng pending.

① Click ⬇ Export SVG trên diagram → tải file .svg

② Mở https://svgtopng.com hoặc Inkscape → convert sang PNG 300 DPI

③ Insert PNG vào Google Docs: Insert → Image → Upload from computer

① Zoom browser 100%, mở diagram cần chụp
